# 03: Accounts with Better Auth

Blocked by: 01

## What to build
Email-and-password accounts, end to end, as described in the spec's "Accounts" section.

- Better Auth with its Drizzle adapter, mounted at `/api/auth/*`, with its tables in a committed migration.
- The first account on an install gets the `admin` role.
- `ALLOW_SIGNUPS=false` refuses sign-up, except for the first account.
- Session middleware for the rest of `/api`: requests without a session get `401`.
- Nuxt pages `/signup` and `/login`, a log-out button, and a route guard that sends logged-out visitors to `/login`. Phone first.
- Add `BETTER_AUTH_SECRET`, `APP_URL` and `ALLOW_SIGNUPS` to `.env.example` and Compose.

## Acceptance criteria
- [x] A visitor can sign up, log out and log back in, in the browser and inside Docker Compose.
- [x] API tests (`app.request()` + PGlite) cover: the first user becomes admin and the second doesn't; sign-ups refused when disabled, except for the first; `401` without a session.
- [x] The pages work at 375 px wide.

## Notes
- Better Auth 1.7.15 with `@better-auth/drizzle-adapter` and the admin plugin (it adds `role`, and later the admin password reset from ADR 7). The schema in `apps/api/src/db/auth-schema.ts` is generated by the `auth` CLI; migration `0001_accounts`.
- The first account becomes admin in a database hook. Two sign-ups at the same instant on a brand-new install could both become admin; accepted for now.
- `ALLOW_SIGNUPS=false` is enforced on the sign-up endpoint only, so an admin can still create accounts later.
- Every `/api` route except `/api/health` and `/api/auth/*` needs a session. Unknown `/api` routes answer `401` when logged out, so routes can't be probed. `GET /api/me` returns the signed-in User.
- The app refuses to start with the example `BETTER_AUTH_SECRET` or one shorter than 32 characters, so a copied `.env.example` now needs a secret before `docker compose up` works.
- Sign-up asks only for email and password; Better Auth's required `name` is set to the part of the email before the `@`.
- Checked in a browser at 375 px, both under `pnpm dev` and in Docker Compose (sign up, admin badge, reload, log out, wrong password, log back in, second User, sign-ups turned off).
