# MyVGC: domain context

MyVGC is a hub where a competitive player tracks their Pokémon VGC experience in the game **Pokémon Champions**: tournaments attended, the teams they brought, who they played, what those opponents brought, and notes on all of it. Teams can be exported to the official VGC teamsheet format.

## Glossary
Draft terms, still to be sharpened in the interview.

- **VGC**: Video Game Championships, the official Pokémon competitive format.
- **User**: someone with a MyVGC account. Each user has a private space; nothing is shared between users in the first version.
- **Team**: a set of up to six Pokémon builds.
- **Tournament**: a competitive event the user took part in.
- **Player**: a person the user has played against.
- **Note**: free text the user attaches to a Player, Team or Tournament.
- **Teamsheet**: the official Play! Pokémon team list document, generated from a Team.
